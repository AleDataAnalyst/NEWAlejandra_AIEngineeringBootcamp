# Módulo 5 · AI Agents Engineering

Sprints **11**, **12** y **13**.

En el Módulo 4 (RAG) aprendiste a **preparar**, **recuperar** y **responder** con conocimiento documentado. En este módulo construyes **agentes**: sistemas que mantienen **estado**, ejecutan **varios pasos** y, más adelante, usan **herramientas** de forma controlada.

```text
Sprint 11  Fundamentos: estado, loop, parada, UI
Sprint 12  Tool use: RAG + API + utils (LangGraph solo panorama)
Sprint 13  Autonomía controlada, HITL, multimodal intro
           → Project Break 2
```

| Sprint | Pregunta |
|--------|----------|
| **11** | ¿Qué es un agente y cómo controla su ciclo con estado? |
| **12** | ¿Cómo usa herramientas (RAG, API, utils) sin perder el control? |
| **13** | ¿Cómo planifica con autonomía y límites? |

**Stack del módulo:** Python + Gemini · dominio agenda cultural · Streamlit como interfaz · sin AWS Bedrock.
