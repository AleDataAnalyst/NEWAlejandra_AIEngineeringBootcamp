# Corpus — Agenda cultural de Madrid

Datos abiertos del Ayuntamiento de Madrid ([datos.madrid.es](https://datos.madrid.es)) más dos textos de apoyo.

| Archivo | Formato | Contenido |
|---------|---------|-----------|
| `faq_agenda_cultural.md` | Markdown | Preguntas frecuentes sobre el dataset |
| `guia_agenda_cultural.txt` | Texto | Guía de uso del dataset |
| `206974-3-agenda-eventos-culturales-100.pdf` | PDF | Documentación de los campos del dataset |
| `206974-4-agenda-eventos-culturales-100-csv.csv` | CSV (`;`, latin-1) | Un evento por fila, próximos 100 días |
