# MC_05 · Spec-Driven Development (SDD)

Masterclass sobre cómo dirigir a un agente de IA de código a partir de una **especificación**, en vez de a base de prompts sueltos.

| Carpeta | Qué es |
|---|---|
| [`SDD_workshop/`](SDD_workshop/) | El sistema SDD completo aplicado al RAG de la agenda cultural de Madrid: constitución, `AGENTS.md`, comandos `/sdd-*` para Copilot, specs y tests. Es el proyecto de la demo en vivo. |
| [`Plantilla/`](Plantilla/) | El mismo sistema en versión genérica para aplicarlo a **tu** Project Break de RAG, con una guía paso a paso y un menú de funcionalidades. |

**Flujo:** Constitución → Spec → Clarificación → Plan → Tareas → Implementación (una tarea, tests primero) → Validación → Cambio (primero la spec).

Empieza por la guía de la [Plantilla](Plantilla/README.md).
