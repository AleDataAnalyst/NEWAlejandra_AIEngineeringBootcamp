# 🎯 Práctica Obligatoria — SQL y Bases de Datos

Esta práctica se compone de dos partes independientes:

| # | Notebook | Qué trabaja |
|---|----------|-------------|
| 1 | [Parte_I_SQL_Game.ipynb](./03_Practica_Obligatoria/Parte_I_SQL_Game.ipynb) | Resolver un caso de asesinato en *SQL Murder Mystery* aplicando queries SQL sobre el modelo de datos de `data/sql-murder-mystery.db`. |
| 2 | [Parte_II_Modelo_BD.ipynb](./03_Practica_Obligatoria/Parte_II_Modelo_BD.ipynb) | Diseñar e implementar en **Google BigQuery** un modelo de datos normalizado (3NF) para un e-commerce, con generación de datos sintéticos y queries de verificación. |

## Organización

Esta práctica es **autogestionada** y pensada para hacerse **de forma individual**: decidís vosotros mismos si la hacéis en solitario o en equipo, y si optáis por grupo (opcional), también sois vosotros quienes los formáis y os organizáis.
